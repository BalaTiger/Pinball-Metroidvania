# 回声轨道 / Echo Orbit

一个“弹珠物理 + Roguelike 构筑 + 固定类银河城地图”的可玩 Web Demo。

## Demo 结构

这个纵向切片覆盖一局游戏从出生到最终 Boss 的完整循环，并将地图扩展为 4096×3072 的分块世界：

1. **静滞中庭**：固定出生点、基础移动教学、第一座折跃站。
2. **失压回廊 / 折光档案馆**：普通敌人、反弹障碍、可从单侧撞开的闸门、绘图师。
3. **脉冲熔炉**：中期 Boss 房；通往后区的出口预先封闭，主角弹射停止且落在房内后才封闭入口并生成 Boss，击杀后开放。
4. **沉默蓄水层 / 偏航圣所**：地图回环、第二座折跃站、更多装备掉落。
5. **空洞冠冕**：最终 Boss 房与本局胜利条件。

地图核心仍由 7 个固定房间和多条走廊组成，外围新增风暴井、离子温室、深渊升降井、沉没环城、苍穹桥列、回声骨库、逆光观测站与零潮静海等区域。世界按 640×640 区块组织，运行时只绘制玩家周围 3×3 区块；碰撞和丢弃检测使用当前已载入几何，跨区块移动时自动刷新。

主线围绕阿刻戎轨道城毁灭前的九分钟循环展开：玩家从静滞中庭醒来，拼合失落坐标、熄灭熔炉并直面零相。每个区域都有背景、信号与目标文本，星图会标出区域边界、区块网格和已探索地点。

## 已实现系统

- 鼠标实时瞄准，点击弹射；预览线与实际移动使用同一次物理模拟，包含墙壁、障碍、敌人与闸门反弹。
- 无重力、有限航程、完整停止后切换回合。
- 只有画面内且已脱离迷雾的敌人会按顺序行动。
- 敌人追击采用带动态碰撞检测的 A* 寻路，能绕开墙体、障碍、关闭的闸门与其他敌人。
- 路径探索与落点视野共同揭开迷雾。
- 数据驱动的多阶段 Boss 遭遇：断压看守、折光典狱长、熔脉巨像、静默利维坦、偏航神谕、授粉母体、环城摄政、逆光观测者与空洞冠冕共九名守卫；Boss 在主角停于对应房内后现身，拥有独立行为、阶段和奖励。
- 敌人随机掉落普通 / 稀有 / 史诗装备；路径经过掉落物时自动拾取。
- 6 个装备槽、8 格背包；行动阶段可点击装备、拖拽排序/替换/丢弃，右键分解为碎片。
- 绘图师：遇见后，本局与之后揭开的迷雾会跨局永久记录。
- 折跃师：遇见的位置跨局永久显示，并在玩家行动阶段开放即时折跃。
- 永久死亡与世界状态重置。
- 单一临时存档：保存退出后可继续；开始新游戏会覆盖；死亡或胜利会删除。

## 操作

- `移动鼠标`：选择方向并预览完整路径
- `鼠标左键`：弹射
- `M`：打开 / 关闭世界地图（也可点击顶部“星图”）
- `点击背包装备`：装入谐振槽
- `点击已装备物`：卸下
- `拖拽装备`：在背包中排序、移动或替换装备槽，拖到可到达地图区域可丢弃
- `右键背包装备`：分解为碎片

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 代码布局

- `src/main.ts`：游戏状态机、物理模拟、回合、存档、Canvas 渲染和 UI 交互
- `src/pathfinding.ts`：敌人追击使用的网格 A*、最小堆开放集与路径端点连接
- `src/world.ts`：分块世界、区域元数据、房间、走廊、障碍、闸门、敌人与 NPC 初始数据
- `src/bosses.ts`：Boss 定义、阶段计算、移动行为与伤害规则
- `src/lore.ts`：区域背景、信号、目标与主线剧情节点
- `src/types.ts`：核心数据结构与存档格式
- `src/style.css`：主界面、菜单、装备栏和弹窗视觉系统
